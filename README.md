# Taskist Reborn

Yazılım geliştirme ekipleri için rol bazlı masaüstü görev otomasyonu (Python + CustomTkinter + SQLite).

## Kurulum

```bash
cd TaskistReborn
pip install -r requirements.txt
python main.py
```

## Özellikler

- Ortak giriş / kayıt (hash'li şifre)
- Ekip (workspace) ve ekip bazlı roller
- Yönetici / Geliştirici / Tester panelleri
- Kod tarayıcı (AST + kurallar)
- Günlük Scrum asistanı
- Bildirim merkezi + e-posta simülasyonu (`logs/email_simulation.log`)
- Profil, gizlilik, takip ve portföy
- Tooltip ve sağdan kayan toast bildirimleri
- Koyu / açık tema

## Demo verisi (opsiyonel)

```bash
set TASKIST_SEED_DEMO=1
python main.py
```
